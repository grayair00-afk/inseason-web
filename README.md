# 인비저블 시즌 웹사이트 — 콘텐츠 업데이트 가이드

코드를 몰라도, 폴더에 파일만 넣고 `update_web.bat`을 실행하면 영상/배경/음악이 웹사이트에 자동 반영됩니다.

## 폴더 구조

```
content/
├── videos.json          영상 목록 (제목, 유튜브 링크, 부제목, 배경음악)
├── backgrounds/          히어로 배경 이미지
│   └── manifest.json     (자동 생성/관리 — 직접 수정할 필요 없음)
└── music/                배경음악 mp3 파일
```

## 1. 새 영상 추가하기

1. `update_web.bat` 더블클릭
2. `새 영상을 추가하시겠습니까? (y/n):` → `y` 입력
3. 제목, 부제목, 유튜브 링크(또는 영상 ID)를 물어보면 입력 (부제목은 없으면 그냥 Enter)
4. 음악 파일이 있다면 번호를 골라 배경음악으로 지정 가능 (없으면 Enter)
5. 자동으로 git에 저장되고 배포됩니다 — **1~2분 후** 웹페이지에 반영됨

새로 추가한 영상은 항상 **기존 영상들의 왼쪽**에 자동으로 쌓입니다 (첫 영상 "블루밍에어"가 오른쪽 고정).

## 2. 새 배경 이미지 추가하기

1. 이미지 파일(jpg/png/webp)을 `content/backgrounds/` 폴더에 복사
2. `update_web.bat` 더블클릭 (영상 추가는 `n`으로 건너뛰어도 됨)
3. 폴더를 스캔해서 새 이미지가 자동으로 목록에 추가되고 배포됨

방문하거나 새로고침할 때마다 히어로 화면 배경이 이 폴더의 이미지들 중 랜덤 순서로 나옵니다.

## 3. 새 배경음악 추가하기

1. mp3 파일을 `content/music/` 폴더에 복사
2. `update_web.bat` 실행 시, 영상 추가 단계에서 음악 목록에 자동으로 나타나 특정 영상에 지정 가능
3. 어떤 영상에도 지정하지 않아도, 파일을 넣기만 하면 사이트 우측 하단 배경음악(♪) 재생목록에도 자동으로 포함됨

## 4. 사용 요약

```
새 배경이미지 → backgrounds 폴더에 복사
새 음악      → music 폴더에 복사
새 영상      → update_web.bat 실행해서 제목/링크 입력
             ↓
   update_web.bat 더블클릭 한 번 → 1~2분 후 웹페이지 반영 완료
```

## 참고

- 배포: GitHub `master` 브랜치에 push되면 Vercel이 자동으로 빌드/배포합니다 (별도 조작 불필요)
- `update_web.bat`은 Node.js가 설치되어 있어야 동작합니다 (없다면 실행 시 안내 문구가 뜸 → nodejs.org에서 설치)
- `videos.json`을 직접 열어 수정해도 되지만(제목/부제목/유튜브 링크/music 필드), 보통은 `update_web.bat`으로 충분합니다
